工作台能力说明

能做什么测连通 / 拉模型 / 加入任务 / 立即刷新 / 取消任务 / 清除任务 / 刷新列表 / 全部提交上游 / 清空任务记录，外加任务列表每行的「提交上游 · 取消 · 获取状态 · 清除」和「当前任务 / 任务列表」双页签。

安全与能力边界「测连通」走的是需要令牌的 /v1/status，不会返回账号明细；任务记录同时承担计费与退款凭据，因此「清除」采用软删除、保留账务依据；服务端只允许启动排队中的任务，失败或已取消的任务会显示为不可启动。

从旧工作台过来本页已完整承接原用户工作台的能力：令牌登录、余额、卡密兑换、批量创建、素材库、任务筛选。数据始终在同一个后台，任务与积分按令牌可直接查到，无需迁移。
